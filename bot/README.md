# 🎄 Новогодний Telegram-бот «2027 от Доктора Алексея Маматова» ❄️

Бот поздравляет с наступающим Новым 2027 годом, пишет случайные пожелания
о здоровье, счастье и благополучии от имени **Доктора Алексея Маматова**,
а затем предлагает поучаствовать в **Новогодней лотерее**: из мешка Деда Мороза
вылетают билетики с номерами от 1 до 10. После выпадения номера появляется
текст **«Напишите свой номер билетика сюда»** с кнопкой (в неё позже будет
вставлена переадресация на поддержку).

Всё оформление — в новогоднем стиле: снег ❄️, гирлянды 🔴🟡🟢🔵, фонарики 🏮✨.

## Сценарий диалога

```
/start
   ↓
🎄 Приветствие + кнопка [🎁 Получить поздравление]
   ↓
Случайное пожелание (здоровье / счастье / благополучие)
подпись: — Ваш доктор Алексей Маматов 🩺✨
+ кнопка [🎰 Участвовать в Новогодней лотерее 🎁]
   ↓
Анимация лотереи: 🎒 мешок → билеты крутятся 🎫💨 → выпадает № 1..10
   ↓
🎫 ТВОЙ БИЛЕТИК № N! + персональное поздравление по номеру
   ↓
«Напишите свой номер билетика сюда» + кнопка
(после реализации — переадресация на поддержку)
```

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | Логика бота (стартовый хук, кнопки, анимация лотереи) |
| `wishes.py` | Тексты пожеланий, подписи, шаблоны сообщений |
| `test_logic.py` | Быстрая проверка данных без Telegram API |
| `requirements.txt` | Зависимости |

## Установка и запуск

1. Получите токен у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. Установите зависимости:
   ```bash
   pip install -r bot/requirements.txt
   ```
3. Запустите:
   ```bash
   export BOT_TOKEN="123456:ABC-DEF..."
   python bot/main.py
   ```
4. Откройте чат с ботом и напишите `/start`.

## Как вставить переадресацию на поддержку

В `bot/main.py` найдите функцию `keyboard_support()`. Сейчас там
`callback_data="support"` (заглушка). Замените её на url-кнопку:

```python
InlineKeyboardButton(
    "📩 Написать номер билетика",
    url="https://t.me/ВАШ_МЕНЕДЖЕР_ИЛИ_ЧАТ_ПОДДЕРЖКИ",
)
```

Номер билетика также можно передавать в deep-link, например:
`https://t.me/support_bot?start=ticket_7`.
